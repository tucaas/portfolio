Designing a unified experience for modern gamers

Game Track is a conceptual mobile app that brings games, achievements, wishlists, and friends from multiple platforms into one seamless experience.

Instead of building another storefront, the project focused on creating a scalable interface that organizes a complex ecosystem through familiar patterns and thoughtful information architecture.

  • Unified library across platforms.
  • Intelligent discovery and recommendations.
  • Social activity and friend tracking.
  • Scalable design system.

Design Challenges

The main challenge wasn't designing beautiful screens, it was organizing a huge amount of cross-platform information without overwhelming the user.

  • Hundreds of games, wishlists, and friends.
  • Multiple platform ecosystems (Steam, PlayStation, Xbox, Nintendo, Epic).
  • Balancing discovery, organization, and social features.
  • Keeping navigation clear as content grows.

Research & Inspiration

Instead of searching for a direct competitor, I analyzed products that successfully solved individual aspects of the experience.

Streaming platforms inspired the organization of extensive content libraries, allowing users to browse large collections without feeling overwhelmed.

Social platforms demonstrated how activity feeds and personal profiles encourage engagement and community interaction.

Gaming platforms provided familiar navigation patterns that players already understand, reducing the learning curve while keeping the interface intuitive.

Rather than copying a single product, the final experience combines interaction patterns users already know into a solution designed specifically for gaming.

Design Approach

The project was guided by a simple objective: make a feature-rich platform feel effortless to navigate.

  • Reduce cognitive load.
  • Prioritize familiar interaction patterns.
  • Reveal information progressively.
  • Design for long-term scalability.

Prioritize Familiarity

Instead of introducing new interaction patterns, the interface builds on conventions users already know.

  • Streaming-inspired content organization.
  • Social patterns for friends and activity.
  • Predictable navigation across the app.

Reducing friction lets users focus on their games—not on learning the interface.

Surface information progressively

Showing every available feature at once would make the application intimidating.

Instead, information is revealed progressively through expandable sections, categorized content and contextual actions, allowing users to focus only on what matters at that moment.

Make discovery effortless

The home screen was designed to answer the questions players ask most frequently.

  • What should I play?
  • What are my friends playing?
  • Are any games on sale?
  • What's new?
  • Which games fit my interests?

Instead of forcing users to search for these answers, the interface brings them directly to the main screen.

Build a Scalable System

Gaming libraries constantly evolve, so the interface was built to grow with them.

  • Reusable layouts.
  • Modular UI components.
  • Expandable content structure.
  • Future-ready navigation.

Organizing Information

Game pages combine trailers, screenshots, reviews, achievements, pricing, DLC, and recommendations. The challenge was presenting all of this without overwhelming users.

  • Grouped related information.
  • Used expandable sections for secondary content.
  • Prioritized the most important actions.
  • Applied the same structure across the application.

The result is an interface that remains easy to scan regardless of content density.

Creating Meaningful Navigation

Navigation was designed around user goals rather than application structure.

  • Browse recommendations.
  • Track friends' activity.
  • Manage wishlists and collections.
  • Move between sections without losing context.

Consistent navigation patterns reduce decision-making and encourage exploration.

Visual Design

The visual language puts game artwork first while maintaining a clean, readable interface.

  • Dark and light interfaces inspired by entertainment platforms.
  • Artwork used as the primary visual element.
  • Typography and spacing establish clear hierarchy.
  • Consistent styling across every screen.

Reflection

This project shifted my perspective from designing individual screens to designing information systems.

  • Prioritizing information became more important than adding features.
  • Hierarchy and structure proved to be as important as visual design.
  • Reusable patterns made the product easier to scale.

If revisiting the project today, I would validate these decisions through usability testing and accessibility reviews before expanding the system further.
